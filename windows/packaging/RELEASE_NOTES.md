The Windows edition, built by the `windows-app` workflow from the commit this release points at.

**This is a draft.** Publishing it would make the installer public, and whether a Windows build may be
distributed at all still depends on the Swiss Ephemeris licence — AGPL with published source, or
Astrodienst's professional licence. That choice is unmade, so whoever presses **Publish release** is
making it knowingly.

The build is **unsigned**, so Windows SmartScreen warns on first run: *More info* → *Run anyway*. Only a
code-signing certificate removes that warning.

### What it is

The same app as the Android edition, from the same astrology engine: charts drawn North or South Indian,
all 66 reading sections and all 16 divisional charts, Today's panchang, the three-year outlook and the
predictions, Kundali Milan with the eight kootas and the South Indian Porutham, Muhurta, Prashna and
horary, numerology, the Chinese side, a birth-time check, and nine reports saved as self-contained pages
you can print to PDF. English and Hindi throughout.

Installs per user — no administrator needed. Everything is worked out on the machine: no account, no
network, and no birth details leaving the computer.
